## 重点3ジャンルの詳細マップ

### ★ IPヘッダ（ジャンル2）

| サブトピック | 押さえるべき点 |
|--------------|----------------|
| 2-1 IPv4ヘッダ構造 | 各フィールドの意味と長さ、IHL の単位、最小20/最大60バイト |
| 2-2 TTL・ICMP | TTL減算と破棄、ICMPタイプ（0/3/5/8/11）、traceroute の仕組み |
| 2-3 プロトコル番号・DSCP | 1/6/17/47/50/51/89/112、DSCP（EF=46 など）、ECN |
| 2-4 フラグメント・MTU | 識別子/フラグ/オフセット計算、DFビット、PMTUD、MSS |
| 2-5 ルータ転送時のヘッダ変化 | 変わるもの（TTL・チェックサム・MAC）と変わらないもの |
| 2-6 サブネット計算 | ネットワーク/ブロードキャストアドレス、ホスト数、CIDR |
| 2-7 IPv6ヘッダ | 固定40バイト、拡張ヘッダ、チェックサム廃止、中継ルータでのフラグメント禁止 |

### ★ ルーティング（ジャンル4）

| サブトピック | 押さえるべき点 |
|--------------|----------------|
| 4-1 経路選択の原則 | ロンゲストマッチ → AD → メトリック の優先順 |
| 4-2 静的経路 | デフォルトルート、フローティングスタティック |
| 4-3 経路集約 | 集約アドレスの計算、集約しすぎによる問題 |
| 4-4 RIP（距離ベクトル） | ホップ数・最大15、カウントトゥインフィニティ、スプリットホライズン |
| 4-5 OSPF | コスト計算、エリア設計、ABR/ASBR、DR/BDR 選出、LSAタイプ、スタブエリア |
| 4-6 BGP | eBGP/iBGP、AS_PATH、LOCAL_PREF、MED、iBGPフルメッシュとルートリフレクタ |
| 4-7 冗長化 | VRRP（仮想IP/MAC、優先度、プリエンプト、トラッキング） |

### ★ セキュリティ（ジャンル6）

| サブトピック | 押さえるべき点 |
|--------------|----------------|
| 6-1 暗号の基礎 | 共通鍵/公開鍵/ハッシュの使い分け、デジタル署名の鍵 |
| 6-2 PKI・証明書 | 証明書チェーン、検証手順、失効確認（CRL/OCSP） |
| 6-3 TLS | ハンドシェイク、前方秘匿性、TLS1.3 の変更点 |
| 6-4 IPsec・VPN | AH/ESP、トンネル/トランスポート、IKE、NATトラバーサル |
| 6-5 FW・IDS/IPS・WAF | ステートフルインスペクション、非対称経路の問題、誤検知 |
| 6-6 認証 | 802.1X の3要素、EAP-TLS/PEAP、RADIUS |
| 6-7 メール・DNSセキュリティ | SPF/DKIM/DMARC、OP25B、キャッシュポイズニング、DNSSEC |
| 6-8 攻撃手法 | SYNフラッド、リフレクション（増幅）攻撃、各対策 |

## シラバス（Ver.4.1）との対応

出典：[IPA ネットワークスペシャリスト試験 シラバス Ver.4.1](https://www.ipa.go.jp/shiken/syllabus/nq6ept00000014fp-att/syllabus_nw_ver4_1.pdf)

シラバスの大項目は**業務の流れ**（要件定義 → 設計 → 構築 → 運用 → 管理 → 評価）で分かれている。具体的な技術は主に **2-1 / 2-2 / 5** の「要求される知識」に書かれている。

> アプリの縦軸は本の章立てに合わせた（[学習計画](学習計画.md)）。この表は、各シナリオがシラバスのどこに当たるかを確認するためのもの。

| シラバス区分 | 主な「要求される知識」 | 対応ジャンル | アニメーション（apps） |
|---|---|---|---|
| 1 要件定義 | 業務要求の分析、トラフィック測定、リスク分析 | 10 | － |
| **2-1 適用技術の調査と評価** | ネットワークの階層・プロトコル・トポロジ・アドレス体系、電子メール・ファイル転送・Web・コンテンツ配信、クラウド／エッジ | 1, 2, 3, 5 | パケットの旅、TCP、DNS、電子メール |
| **2-2(1) 設計：アーキテクチャ** | 通信方式、トラフィック・スループット、アドレス設計、待ち行列理論、リモート／モバイルアクセス、無線LAN、IoT、SDN・SD-WAN・NFV、高可用性設計 | 2, 4, 7, 9 | NAPT、DHCP、VLAN、OSPF、BGP、VXLAN |
| **2-2(2) 設計：セキュリティ** | セキュリティホール、機密性・完全性・可用性、関連法規、認証・暗号化・アクセス制御 | 6 | TLS 1.3、IPsec VPN、802.1X、ステートフルFW |
| **2-2(3) 設計：信頼性** | 信頼性、経済性、ネットワークサービス、クラウドサービス（SaaS/PaaS/IaaS） | 8, 9 | VRRP、STP |
| 3 構築とテスト | 導入作業、テスト仕様の作成・実行・評価 | 10 | － |
| 4 運用・保守 | 保守計画、更新、バックアップと回復、構成管理 | 10 | － |
| **5 ネットワークシステムの管理** | 監視（監視データの収集・ツール）、障害の分析と復旧、性能分析、セキュリティ侵害の分析と対応（IDS/IPS） | 6, 10 | SNMP、traceroute |
| 6 評価 ／ 7 コンサルティング | 評価・改善提案、技術的アドバイス | 10 | － |

> 1・3・4・6・7 は午後の設問で「手順」や「考え方」として問われることが多く、アニメーションよりも事例問題での演習が向いている。
