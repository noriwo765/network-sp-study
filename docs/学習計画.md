# 学習計画（本の章 × アプリで動作確認）

使用する本：[［左門式ネスペ塾］手を動かして理解する ネスペ「ワークブック」](https://gihyo.jp/book/2022/978-4-297-12996-5)（技術評論社）

## 進め方

1. 本の章を読み、**ステップ1（短答式）**で理解を確認する
2. アプリで同じ章のアニメーションを開き、**予想モード**をオンにしてフレームの中身を予想しながら再生する
3. 本の**ステップ2（手を動かして考える）・ステップ3（実戦問題）**に取り組む
4. アプリの**単語カード**と**理解度チェック**で同じ章を仕上げる（移動中のスキマ時間向け）
5. 下の表の「状態」を更新し、気づいたことやアプリの誤り・分かりにくい点を「メモ」に書く
   → メモを伝えてもらえれば、アプリを修正・追加する

- アニメーション：[apps/packet-flow.html](../apps/packet-flow.html)（ページ上部の章ボタンから選ぶ）
- 単語カード：[apps/terms.html](../apps/terms.html) ／ 理解度チェック：[apps/check.html](../apps/check.html)
- 計算ドリル：[apps/drills.html](../apps/drills.html)
- 状態：`未` → `読了` → `確認済` → `演習済`
