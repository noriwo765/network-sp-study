# quizzes — 理解度テスト

解答・解説・自己採点シート付きのテスト。サブトピック番号は [ジャンル一覧](../docs/ジャンル一覧.md) に対応。

| ファイル | 内容 |
|---------|------|
| [重点3ジャンル診断テスト.md](重点3ジャンル診断テスト.md) | IPヘッダ／ルーティング／セキュリティ 各10問、計30問（記述式） |
| [check.js](check.js) | 本の章ごとの4択問題データ。アプリの[理解度チェック](../apps/check.html)で使う |

## check.js のデータ形式
```js
{ id: '11-1', ch: 本の章番号, q: '問題文', choices: ['選択肢' ×4], answer: 正解の添字（0始まり）, explain: '解説' }
```
選択肢は表示時にシャッフルされるので、正解を先頭に書いてよい。追加・修正したら `node apps/tools/check.js` で確認する。
