# 解答記録

ワーク演習（[apps/work.html](../apps/work.html)）で **AI 採点するたびに、その時点のスナップショットがここへ自動保存**される（ローカルサーバ経由で開いているときのみ）。

## 構成（回ごとに別ファイル）
問題ごとのフォルダの中に、採点のたびに日時つきの新規ファイルが増えていく（**上書きしない**ので、何周しても全回が残る）。

```
解答記録/
  令和6年_午後Ⅰ_問1_○○/
    2026-11-02_143500.md   ← 1周目
    2026-11-09_210300.md   ← 2周目
    ...
  令和6年_午後Ⅱ_問1_△△/
    ...
```

- 1ファイル＝その採点時点の**問題まるごとのスナップショット**（全設問の問題文・公式解答例・**あなたの解答**・AI採点〔判定／点数／加点点／不足・誤り／差分／アドバイス／模範解答〕）。
- 「まとめて採点（提出）」は1回の提出＝1ファイル。
- ファイル名は日時順に並ぶので、周回の推移を上から順に追える。

## Git 管理
記録ファイルは個人の学習データなので **`.gitignore` 済み**（この `README.md` だけ追跡）。GitHub には上がらない。

> 履歴の本体は `server/history.json`（全回を構造化して保持）。このフォルダはその「回ごとの読み物」版。端末間の引き継ぎは履歴ファイル／バックアップ機能で行うので、このフォルダを持ち運ぶ必要はない。
