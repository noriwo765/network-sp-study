# 配点画像の取り込み

ワーク演習の配点は設問ごと、複数欄の設問は欄ごと（a/b/c、機器①、① など）に持つ。
画面で1つずつ入力する代わりに、画像から読み取った値を `apps/tools/haiten-set.js` で登録する。
`server/haiten.json` は手で編集しない（欄ラベルの検証と rev の更新がツールでしか行われないため）。

## 手順

1. **対象の問題を特定する。** 年度・区分・問番号から問題 id（例：令和5年 午後Ⅰ 問3 → `r5_pm1_q3`）を決める。画像から分からなければユーザーに聞く。
2. **欄の単位を確認する。**
   `node apps/tools/work-check.js --fields r5_pm1_q3`
   「（1欄）」の設問は数値1つ、それ以外は表示された欄ラベルごとに点数を持つ。
3. **画像を読み取る。** 設問ごと・欄ごとの点数を拾う。
   - 読めない・あいまいな値は推測で埋めない。表にして「読み取れなかった」と示す。
   - 画像は設問の合計点だけで、アプリは欄別、のように単位がずれるときは、勝手に均等割りしない。ユーザーに割り振りを確認する（「a〜c で計6点なら各2点でよいか」など）。
   - 合計の目安：ネスペの午後Ⅰは1問50点、午後Ⅱは1問100点。大きくずれたら読み取りミスを疑い、ユーザーに確認する。
4. **読み取り結果をユーザーに見せて確認を取る。** 設問・欄・点数・問題合計の表で示す。了承を得るまで書き込まない。
5. **登録する。** スクラッチパッドに次の形の JSON を書き、まず `--dry-run`、問題なければ本実行する。
   ```json
   { "r5_pm1_q3": { "設問1": { "a": 2, "b": 2 }, "設問3(1)": 4, "設問3(3)": { "機器①": 2, "作業ミス": 4 } } }
   ```
   `node apps/tools/haiten-set.js <JSON> --dry-run` → `node apps/tools/haiten-set.js <JSON>`
   NG が出たら、欄ラベルや数値の形を `--fields` の表示に合わせて直す。
6. **反映を確認する。** ユーザーに、開いているワーク演習のページを再読み込みしてもらう。再読み込みすると、ファイル側の新しい配点が採用される。
   `node apps/tools/work-check.js` で配点に NG・要確認が無いことを確かめる。
7. **コミットする。** `server/haiten.json` は Git 管理なので、登録後にコミットする（例：`配点予想を登録（R5午後Ⅰ問3）`）。

## 注意

- 登録した後に、再読み込みしていない古いページで配点を編集すると、保存時に「ファイル側の配点の方が新しいため上書きしませんでした」と出る。再読み込みしてから入力し直せばよい。サーバは古い rev での上書きを拒否する仕組みになっている。
- ツールが置き換えるのは指定した設問だけで、ほかの設問の配点は残る。
